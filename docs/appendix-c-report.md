# Appendix C-rapport

## Sammanfattning

Appendix C har skapats som ett praktiskt beslutsstöd för plattforms- och ramverksval. Appendixet kompletterar:

- Kapitel 14: Plattformar, produkter och ramverk att överväga
- Kapitel 15: När man väljer vad
- Appendix A: Kommersiella AI-plattformar och molntjänster
- Appendix B: Open source-modeller, ramverk och egen drift

Appendix C är avsiktligt inte en produktkatalog. Det innehåller i stället beslutsmatriser, urvalsmallar och dokumentationsmallar som kan användas när Tullverket Aurora ska omsätta målarkitekturen i konkreta vägval.

## Skapade delar

Appendix C innehåller bland annat:

- urvalsmall för AI-byggblock,
- matris för SaaS, plattform eller egen drift,
- matris för publikt moln, sovereign cloud, privat moln eller on-premises,
- matris för RAG, fine-tuning eller egen modellservering,
- matris för central plattform, federerad modell och hub-and-spoke,
- matris för kommersiellt, open source eller blandat ekosystem,
- matris för vektordatabas och sökplattform,
- matris för agentfunktioner och automatiserade arbetsflöden,
- matris för säkerhets- och guardrails-nivå,
- mall för arkitekturbeslut,
- AI-use-case canvas för plattformsval,
- mall för leverantörs- och ramverksbedömning,
- beslutsflöde för Tullverket Aurora,
- exempel på RAG-plattformsval,
- exempel på bedömning av egen modellservering,
- samlad checklista före produktbeslut.
